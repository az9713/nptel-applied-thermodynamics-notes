# Workflow

The reader and production sequence follow the closest prior NPTEL projects. Stanford CS229 provides the supplementary section-to-recording and dual Markdown/HTML conventions. [Computational Thermodynamics and Kinetics of Materials](https://github.com/az9713/nptel-computational-thermodynamics-kinetics-materials-notes/blob/main/WORKFLOW.md) · [Diffusion in Solids](https://github.com/az9713/nptel-diffusion-in-solids-notes/blob/main/WORKFLOW.md) · [Stanford CS229](https://github.com/az9713/cs229-machine-learning-notes)

1. Inventory the supplied playlist with immutable video IDs. Reconcile the original IIT Madras catalog, its expanded edition, tutorial recordings, and the private Psychrometry Part 5 slot.
2. Acquire English captions and retain both raw tracks and normalized text locally. Sample course slides and board work where they resolve notation, properties, or numerical ambiguities. Record source limitations in the notes.
3. Use the source-analysis, transcript-grounded-textbook, STEM textbook, and rigorous-explainer workflows to plan the scope and notation. Write the first full chapter and run its lab before finalizing the remaining chapter groups. Follow recording topic order within a coherent concept sequence and link into the original videos.
4. Develop a worked device case, conservation equations and limiting assumptions, primary technical references, numerical checks, and solved problems. Label independently constructed examples and use authoritative property data for real-fluid examples.
5. Review chapter mathematics, signs, units, and numerical calculations independently of the author using the science-editor workflow. Repair located defects and rerun affected checks. Validate the book’s internal links, source coverage, mathematical rendering and offline reading.
6. Publish the generated site, Markdown and lab code from the repository root. Check the clean source-free rebuild and compare the live GitHub Pages files to the committed release. Raw media, captions, frame samples, original input notes and private review material remain outside Git. Remove downloaded video files after verification while keeping the local transcripts.

The public source map inventories the original recordings and the chapter relationships. The review and validation reports record the checks actually performed.
