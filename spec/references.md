# Course and technical references

- The [original NPTEL catalog](https://nptel.ac.in/courses/112106314) identifies Applied Thermodynamics at IIT Madras and Prof. Babu Viswanathan. The [expanded catalog](https://nptel.ac.in/courses/112106419) credits Prof. V. Raghavan and provides 72 public recordings. The [supplied playlist](https://www.youtube.com/playlist?list=PLbMVogVj5nJRgXRZ0xEoBfWELmSo6JvvZ) adds one private slot. The [source map](source-map.html) reconciles catalog and playlist order.
- [MIT Unified Engineering, Thermodynamics and Propulsion](https://web.mit.edu/course/16/16.unified/www/FALL/thermodynamics/notes/notes.html) develops the balances and air-standard cycle models used to check several derivations.
- [IAPWS-IF97](https://iapws.org/technical-guidance/release/IF97-Rev) defines thermodynamic property relations for fluid water in industrial calculations, including saturation. [NIST SRD 69](https://webbook.nist.gov/chemistry/fluid/index.html.en-us.en) provides independent fluid-property lookups. Report the property reference convention with numerical values for enthalpy and entropy.
- [NASA Glenn’s ideal Brayton cycle](https://www.grc.nasa.gov/www/k-12/BGP/brayton.html) shows the relation between the compressor, turbine, and idealized cycle. The [isentropic-compression derivation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/isentrophic-compression/) is a check for the calorically perfect gas formulas.
- [NACA Report 1135](https://www.nasa.gov/wp-content/uploads/2023/03/equations-tables-charts-compressibleflow-report-1135.pdf) gives the quasi-one-dimensional compressible flow equations and normal shock ratios for a calorically perfect gas.
